# Indian Art History Interactive Map

A lightweight interactive atlas of Indian artistic traditions.

## Tech
- HTML5
- CSS3
- Vanilla JavaScript
- Leaflet.js
- OpenStreetMap

## Run
1. Open this folder in VS Code.
2. Open `index.html` with Live Server, or simply open it in a browser.
3. Use the map markers, era filters and search box to explore art centers.
4. Choose **Surprise me** to jump to a random location from the current results, or **Reset filters** to restore the full map and its default view.
5. If a search has no matches, clear it or reset the filters to continue exploring.

## Images
The project works even if the image files are not present because the detail image is hidden when an image is unavailable. Add your own copyright-safe images to `assets/images/` using the filenames referenced in `script.js`.

## Note
Historical dates and descriptions are intentionally concise for an educational prototype and should be fact-checked before academic publication.
